## Descrizione del progetto
Il progetto mira a sviluppare un modello in grado di generare automaticamente varianti sostenibili di regole trigger-action per smart home, preservando l’intento funzionale dell’utente. Attraverso l’uso della Direct Preference Optimization (DPO) e di una eco-metrica ispirata alla letteratura sul comportamento energetico sostenibile, il sistema apprende a preferire configurazioni che riducono i consumi energetici e gli sprechi, migliorando l’efficienza delle automazioni domestiche anche in assenza di dataset annotati tramite preferenze sintetiche.

## Tecnologie utilizzate:
- Python
- Pycharm
- Overleaf
- Github
